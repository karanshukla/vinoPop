Text actions for Linux,
without leaving where you are.

Highlight anything. A small popup appears with context-aware actions - open URLs, run commands, ask an AI, transform text. Inspired by PopClip on macOS, built for X11 and native KDE Plasma 6 / Wayland.

Install

Runs on X11 and native KDE Plasma 6 / Wayland. GNOME Wayland runs through XWayland.

1. System dependencies

# Ubuntu / Linux Mint / Debian
sudo apt-get install -y python3 python3-gi python3-gi-cairo gir1.2-gtk-4.0 \
    gir1.2-adw-1 xclip xdotool xdg-utils python3-xlib

# Fedora
sudo dnf install -y python3 python3-gobject gtk4 libadwaita \
    xclip xdotool xdg-utils python3-xlib

# Arch
sudo pacman -S python python-gobject gtk4 libadwaita \
    xclip xdotool xdg-utils python-xlib

Needs GTK 4.14+ and libadwaita 1.5+ (Ubuntu 24.04, Fedora 40 or newer). Optional: gtk4-layer-shell (gir1.2-gtk4layershell-1.0 on Ubuntu 24.10+) for native popup placement on KDE/wlroots Wayland; on GNOME vinoPop runs on XWayland automatically.

2. Clone & install

git clone https://github.com/GaimsDevSoftware/linuxpop.git ~/linuxpop
cd ~/linuxpop
bash install.sh
python3 ~/linuxpop/main.py    # start now without logging out

3. Use it

  • Highlight any text on screen → popup appears with actions
  • Press Super+Shift+Y → popup on current selection at cursor
  • Press Super+Shift+V → clipboard & snippets picker
  • Right-click the tray icon → Settings, Plugins, About
Tip: the first time you open Plugins, browse the catalogue. Most of LinuxPop's power lives in plugins - install only what you'll use.

Three ways to extend it
